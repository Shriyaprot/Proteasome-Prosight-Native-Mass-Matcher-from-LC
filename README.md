# Proteasome ProSight Native Mass Matcher V8

V8 uses the detailed mouse proteasome reference workbook supplied by the user. The bundled normalized library preserves subunit, accession, sequence variant, processing/PTM state, calculated mass, sequence, and whether the source mass cell was highlighted as a commonly encountered tissue form.

Direct matching uses only the reference masses and the user-selected Da/ppm tolerance. Historical experimental measured masses and STD values are not used.

Excel output sheets: Combined results, Encountered candidates, Matched subunits, Reference library.
